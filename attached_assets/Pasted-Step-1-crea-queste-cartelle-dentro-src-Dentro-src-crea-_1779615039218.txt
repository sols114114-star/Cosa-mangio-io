Step 2 — prima sposta SOLO dati alimenti
Crea file:
Plain text
src/data/foods.js
Dentro metti da App.jsx queste parti:
JavaScript
const extraPublicFoods = [...]
const publicFoods = [...]
publicFoods.push(...extraPublicFoods);

const defaultFoods = [...]
e alla fine del file aggiungi:
JavaScript
export { publicFoods, defaultFoods };
Poi in App.jsx cancelli quelle parti e in alto aggiungi:
JavaScript
import { publicFoods, defaultFoods } from './data/foods';
Step 3 — crea file impostazioni
Crea:
Plain text
src/data/constants.js
Sposta dentro:
JavaScript
const STORAGE_KEY = ...
const mealTypes = ...
const defaultMealTargets = ...
const defaultDailyTargets = ...
const defaultMacroPercents = ...
const carbSpeedOptions = ...
const sourceMeta = ...
Alla fine:
JavaScript
export {
  STORAGE_KEY,
  mealTypes,
  defaultMealTargets,
  defaultDailyTargets,
  defaultMacroPercents,
  carbSpeedOptions,
  sourceMeta,
};
In App.jsx metti:
JavaScript
import {
  STORAGE_KEY,
  mealTypes,
  defaultMealTargets,
  defaultDailyTargets,
  defaultMacroPercents,
  carbSpeedOptions,
  sourceMeta,
} from './data/constants';

Però carbSpeedMeta e foodSourceMeta usano carbSpeedOptions e sourceMeta, quindi dentro helpers.js devi mettere in alto:
JavaScript
import { carbSpeedOptions, sourceMeta } from '../data/constants';
In App.jsx importi:
JavaScript
import {
  dateKeyLocal,
  monthKeyLocal,
  todayKey,
  round1,
  uid,
  calcEntry,
  carbSpeedMeta,
  foodSourceMeta,
  scaleRecipeIngredients,
  getWeekRange,
  portionLevel,
